Open Speech ASR 保留完整功能版本，不为商店审核裁剪快捷键和本地模型能力。下载安装后，你可以用系统级快捷键在任意文本框里完成语音输入。

本地 Qwen3-ASR

默认识别引擎在 Swift 进程内运行，安装包已包含 Qwen3-ASR 1.7B 4bit 模型，减少额外配置。

Gemma 文本润色

识别结果可继续通过本地 Gemma E4B 做格式整理、语气修正、术语保留和自定义提示词处理。

快捷键语音输入

支持按住说话、切换录音等工作流，把转写结果直接送回当前应用，适合写邮件、笔记和聊天。

多引擎可选

保留 SenseVoice + Gemma、本地 Qwen3-ASR + Gemma，以及 OpenAI 兼容第三方 API 模式。

隐私边界清楚，默认本地优先

应用本身不依赖 Open Speech 服务器。默认模式下，语音识别和文本润色都在本机完成；当你主动切换到第三方 API 模式时，才会向你配置的服务商发送必要内容。

默认识别 Qwen3-ASR 本地模型，运行在 macOS 应用进程内。
默认润色 本地 Gemma E4B 后端，处理提示词、词表和输出语言。
第三方 API 仅在你开启并填写 API 配置后使用，本地 Python/Gemma 会保持关闭。
权限说明 首次使用需要授予麦克风、辅助功能或输入监控等 macOS 权限，用于录音、快捷键和粘贴结果。

安装与系统要求

下载 DMG 后拖入 Applications。首次启动时，按系统提示授予需要的权限；如果 macOS 提示来自互联网，请在系统设置中允许打开。

系统 macOS，建议 Apple Silicon 机型。
